# plans/

This directory contains planning and phasing documents for fauxbooks. It is not architecture (that lives in `architecture/`) and not product rationale (that lives in `docs/`). It is sequencing: what ships when and why in that order.

## Contents

| File | What it covers |
|---|---|
| [`roadmap.md`](roadmap.md) | v0.2, v0.3, and v0.4 candidate features; explicit non-roadmap items |
| `implementation-plan.md` | Phased v0.1 implementation plan with done-when criteria per phase. Added when implementation begins. |
