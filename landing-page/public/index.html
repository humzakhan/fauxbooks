fauxbooks github ↗

Synthetic accounting data
that already reconciles.

A deterministic Go CLI. Same seed in, byte-identical books out — balanced by construction, not by a pass.

$ fbx gen monthly-close --seed 1 --out ./books

go install github.com/humzakhan/fauxbooks/cmd/fbx@latest

deterministic

same seed → same bytes, every OS

reconcilable

Σ debits = Σ credits, every run

single binary

no CGo, no deps · csv · jsonl · xlsx

Examples

One run writes a complete double-entry close — 19 CSVs and a manifest.

What it looks like gl.csv
entry_id      account   debit             credit
JE-00000001   5000      5910.100000000    0.000000000
JE-00000001   1300      0.000000000       5910.100000000

0.00 ✓ balanced

Decimals as exact strings, 9 fractional digits. No floats, ever. Every entry: Σ debits = Σ credits.
